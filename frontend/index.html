Agent 聊天接入（MCP / Skill）

MCP 和 Skill 是让同一个 Agent 调用本软件的两种方式，任选一种即可；也可同时配置，不互斥。同一任务使用一种方式提交。

客户端已连接 MCP，可直接使用；希望通过技能包调用并按需启动软件，可选择 Skill。这里的接入配置与模型 API 配置独立。

MCP：在客户端添加工具连接

未检测到客户端连接

本程序内置 MCP 服务器：在 Claude Code、Codex 这类客户端里填下面的地址，就能让你的 agent 直接把视频转成字幕稿或笔记。任务仍在这台机器上跑，请先让本程序开着。

MCP 地址
http://127.0.0.1:8765/mcp/http

这台机器没装 mcp 依赖，上面的地址暂时连不通（网页端和任务本身不受影响）。装齐 backend/requirements.txt 里的依赖后重启即可。

Skill：导出技能包，按需启动软件

将 Skill 安装到支持技能的 agent，即可在聊天中发送视频链接，调用本软件生成字幕或笔记。无需配置 MCP。

  1. 选择保存文件夹，导出后解压 ZIP。
  2. 在 agent 中导入 AI-Video-Note 文件夹，或将整个文件夹复制到该客户端指定的 skills 目录；不要只复制 SKILL.md。
  3. 刷新技能列表或重启 agent，确认技能已加载。
  4. 在 agent 聊天中要求使用 AI-Video-Note 处理视频链接；Skill 会按需启动本软件后台服务。
保留包内 startup.json；软件移动后请重新导出 Skill。agent 需要 Python，以及启动本机程序和访问本机服务的权限。任务结束后可从托盘退出软件。
模型档案 每个档案各自记住模型与地址；自定义接口可保存多个。

安装显卡加速组件

        
按当前显卡准备所需组件，已有可用组件会直接复用。

        

            
需要 CUDA 12.x 和 cuDNN 9（CUDA 12 版本）。

            
下载约 1.3 GB，安装后约 1.9 GB。安装到系统标准目录时，可能需要在 Windows 窗口中确认管理员权限。

        

        

            
需要 Vulkan 识别组件 1.9.1，下载约 35 MB，将安装到 NuGet 标准包目录。
